Your PC.

RemoteKingdom brings the desktop and games of your Windows PC to a TV with Android TV or Google TV. Picture, sound, remote and gamepad – no HDMI cable across the room.

Download the server for Windows TV app — join the tests

Server: Windows 10 or 11 (64-bit). App: Android TV / Google TV, phones and tablets. Built on the standard RDP protocol – what works with other clients and servers.

What it does

Smooth picture

Hardware H.264 encoding on the PC and hardware decoding on the TV – up to 60 frames per second.

Gamepad play

A PlayStation 4 controller is recognized as a DualShock 4, so games show ✕ ○ □ △ button prompts. Rumble still works.

Adapts to your network

Picture quality adjusts to your Wi-Fi by itself, so the picture keeps moving on a weaker connection.

Sound

Everything that plays on the PC can be heard on the TV.

Remote, mouse, keyboard

The TV remote is enough (hold OK for mouse mode). A mouse and keyboard connected to the TV work too.

Secure

Encrypted connection (TLS). The TV connects only after pairing with a PIN shown on the PC.

Even before sign-in

The server runs as a Windows service from the moment the PC starts. You can sign in remotely on the sign-in screen (even to a different account), enter your PIN on the lock screen and confirm UAC prompts.

Windows Remote Desktop too

The app also connects to the built-in Windows Remote Desktop (Windows Pro), NLA sign-in included. Note: connecting to a home Windows PC signs out whoever is sitting at the computer – client Windows has only one session. Fine for desktop work; for games and video the RemoteKingdom server is better.

TV, phone, tablet

Runs on Android TV and Google TV, and on phones and tablets with Android 7 or later – in portrait and landscape.

English and Polish

The app follows the language of your phone or TV: English or Polish.

Standard RDP protocol

RemoteKingdom speaks the regular Remote Desktop Protocol (RDP), so it works both ways: you can connect to the server with other RDP clients, and the TV app can connect to a PC without our server. The full feature set, though, comes only with the pair: RemoteKingdom app + RemoteKingdom server.

How it looks

The TV app

RemoteKingdom for Android TV and Google TV – fully usable with the remote, in English or Polish.

On the connection screen

  • Find servers – finds PCs with RDP on your home network and tells RemoteKingdom, Windows Remote Desktop and others apart
  • PC address and port remembered for next time
  • Start Steam (Big Picture) right after connecting
  • Show connection statistics – ping, frames per second, Mb/s and gamepad battery level in a corner, plus how the picture is sent (H.264 with the current bitrate and frame rate cap, or bitmaps)
  • Pairing with the PC by PIN on the first connection

During a session

  • hold Back – disconnect
  • hold OK – mouse mode (arrows move the pointer)
  • SELECT + START on the gamepad – screenshot saved on the PC
  • Reconnects by itself after a short Wi-Fi drop
  • Warns you if the PC's certificate changes

Get started

  1. Install the server

    Download the installer on your Windows PC and run it. By default the server installs as a Windows service: it starts together with the PC, even before you sign in. If Windows has marked your home network as public, the installer warns you – switch it to private, otherwise the firewall will not let the TV in. While the server runs, its icon sits in the notification area next to the clock – its menu shows the PC's address and connected devices and lets you quit the server.

  2. Install the TV app

    Find RemoteKingdom on Google Play on your TV and choose "Find servers" or enter your PC's IP address (e.g. 192.168.0.10).

  3. Pair and play

    The first time, a 6-digit code appears on the PC – type it on the TV. After that, connecting is automatic.

Requirements and tips

Requirements

  • Windows 10 (1809 or later) or Windows 11, 64-bit
  • A TV or box with Android TV / Google TV, or a phone or tablet with Android 7+
  • PC and TV on the same home network
  • For gamepad play: the ViGEmBus driver (the installer offers to open its page)
  • The system must have Media Foundation: on Windows 10/11 “N” editions install the “Media Feature Pack”, and on Windows Server enable the Media Foundation feature

For the smoothest picture

  • Connect the PC to the router with a cable – it makes the biggest difference
  • On Wi-Fi, use the 5 GHz band, not 2.4 GHz
  • Pause big downloads (game updates) while playing
  • Turn on connection statistics to see ping and frame rate

FAQ

The app says the server is not responding

Check that the server is running on the PC (the RemoteKingdom icon next to the clock; if it is missing, start “RemoteKingdom Server” from the Start menu), that the IP address is correct and that the PC and TV are on the same network. The server uses port 3389 by default. If a window about the missing MFPlat.dll file appears when the server starts, the PC is missing Media Foundation – see “Requirements and tips”.

The built-in Windows Remote Desktop uses that same port. If you have it turned on, the RemoteKingdom server will not start – it exits silently and the app only says it cannot connect. To fix this, turn Remote Desktop off (Settings → System → Remote Desktop) or start the RemoteKingdom server on a different port – the port number is given as the first argument (e.g. 3390). If the server will not start, look at the file %ProgramData%\RemoteKingdom\server\rk_server.err (server as a service) or %LOCALAPPDATA%\RemoteKingdom\rk_server.err (plain program): you will find the line [Main] Fatal: bind() failed: 10048.

If the server is running and the TV still cannot connect, check whether Windows has marked your home network as public. On a public network the firewall blocks connections to the server (a safeguard in a café or hotel, for example). You can change this in Settings → Network & internet → Wi-Fi or Ethernet → network properties → Network profile type → Private network.

How do I find my PC's IP address?

Easiest: choose “Find servers” in the app, or click the RemoteKingdom icon next to the clock on the PC – its menu shows “This PC's address”. You can also open Windows Settings → Network & internet → your connection's properties and read the “IPv4 address”, or run ipconfig in a command prompt.

Can I connect with the regular Windows Remote Desktop (mstsc)?

Yes. If Remote Desktop has no saved password, a RemoteKingdom sign-in screen appears after connecting – enter the user name and password of a Windows account on this PC (for a Microsoft account: its email address and password, not the PIN). After 3 wrong attempts the server disconnects.

Can I sign in with a PIN or Windows Hello?

With the RemoteKingdom server running as a service (the default) you see the real Windows lock screen and enter your PIN just as you would at the PC. The server's own sign-in screen (shown in mstsc when no password is saved) accepts only the Windows account password (for a Microsoft account: the account password, not the PIN).

In the built-in Windows Remote Desktop, PIN and Windows Hello do not work – the sign-in screen shows only password and smart card.

With a Microsoft account that has the “require Windows Hello” option turned on, signing in to Remote Desktop with just the password may also fail. Turning that option off, or signing in with the password once locally on that PC, helps.

Can the app connect to a PC without the RemoteKingdom server?

Yes, if the PC runs Windows Pro with Remote Desktop turned on (Settings → System → Remote Desktop). The app asks for the Windows user name and password. By default the password is not stored. You can have it remembered by ticking the option in the sign-in window – the password is then stored encrypted with your device's key. Gamepads, PIN pairing and H.264 video work only with the RemoteKingdom server.

Does connecting sign out whoever is at the PC?

Yes, if you connect through the built-in Windows Remote Desktop (Windows Pro). Client Windows has only one session, so whoever is sitting at the computer gets signed out. Server editions of Windows allow several sessions at once, but home Windows 10/11 Pro does not.

The app asks whether to trust a new certificate

This happens after reinstalling the server or Windows, and also once after switching the server to a Windows service (the service has its own certificate). If it is your PC and you changed nothing, choose “No” and check that you are connecting to the right address.

How do I disconnect or use the mouse with the remote?

Hold Back to disconnect. Hold OK for mouse mode: the arrows move the pointer, OK clicks.

Windows service or plain program?

The installer chooses a Windows service by default. The server then runs from the moment the PC starts, even when nobody is signed in, so you can sign in remotely on the sign-in screen, enter your PIN on the lock screen and confirm UAC prompts. Signing out or switching users disconnects you briefly – the app reconnects.

You can also choose a plain program that starts when you sign in. Then the sign-in screen, lock screen and UAC prompts are not visible remotely: the picture freezes and the keyboard does not work until someone at the PC dismisses them. To change how the server starts, run the installer again and pick the other option (since 0.11.1 the previous one is then removed).

Windows warns about an unknown publisher

The installer is not code-signed yet. Click “More info” → “Run anyway”. Only download the installer from this page.
